Adversarial / deliberately hard cases

✓ Passes Checkout — card details card

cardName (autocomplete=cc-name) is deliberately treated as PII — a cardholder's name tied to a payment form is worth protecting alongside the card number itself.

✓ Passes Government KYC form — Aadhaar aadhaar

2345 6789 0124 is a Verhoeff-checksum-valid test number (real Aadhaar numbers always are) — see benchmark/README.md.

✓ Passes Product page — quantity and SKU true-negative

Tests that generic numeric/alphanumeric fields (quantity, SKU) don't trigger card/phone/Aadhaar false positives.

✓ Passes Job application form phone

portfolioUrl and resumeUpload are true negatives — a URL or file-picker isn't itself sensitive text.

✓ Passes Shipping address only address

city is a true negative — a bare city name field carries far less identifying weight than street/postal code.

✓ Passes Phone number embedded in visible text phone

Tests the text-pattern fallback on non-input elements, not just input type/autocomplete.

✓ Passes Order reference number (card-regex false-positive risk) true-negative

ADVERSARIAL: a 16-digit grouped reference number that isn't actually a card, and correctly fails a Luhn checksum (unlike a real card number would).

✓ Passes International phone format phone

ADVERSARIAL: type=tel still catches this (type-based signal doesn't care about format), but if type were missing this UK-format number would likely miss the US-style phone regex. Kept as a reminder of format coverage limits.

✓ Passes Decorative / icon image (non-photo) true-negative

Tests that non-face images (a logo) don't get swept up by the alt-text keyword fallback.

✓ Passes Embedded payment widget (iframe) iframe

We deliberately don't scan inside iframes for precise per-field redaction (cross-frame coordinate math is easy to get subtly wrong, and untestable here without a live cross-origin iframe). Instead every iframe is blacked out in full, unconditionally — the screenshot already captures iframe pixels regardless of frame origin, so this closes that leak without needing to know what's inside.
